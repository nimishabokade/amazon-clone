# 🛒 Amazon Clone

A frontend clone of the Amazon homepage built using **HTML and CSS**.  
This project was created to practice webpage structure, styling, layouts, Flexbox, and responsive design.

## 🔗 Live Demo


👉 [View Live Website](https://nimishabokade.github.io/amazon-clone/)

## 📂 GitHub Repository

👉 [View Source Code](https://github.com/nimishabokade/amazon-clone)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Git & GitHub
- GitHub Pages

## ✨ Features

- Amazon-style navigation bar
- Amazon logo section
- Delivery location section
- Search bar with category selection
- Language section
- Sign-in and account section
- Returns & Orders section
- Shopping cart
- Navigation panel
- Hero section
- Product category cards
- Footer with multiple sections
- Hover effects
- GitHub Pages deployment
